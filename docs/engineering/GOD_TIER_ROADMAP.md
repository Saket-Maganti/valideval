# God-Tier Roadmap

## Phase 1: Offline MVP

- Keep the toy audit deterministic and runnable without internet.
- Maintain schemas, cached matrices, core diagnostics, report cards, and tests.

## Phase 2: Research Artifact

- Fill the paper from reproducible audit outputs only.
- Maintain claims ledger discipline.
- Release reproducibility bundles with environment capture and hash verification.
- Use reviewer-risk mode before public drafts.
- [ ] Execute the NeurIPS readiness plan in `docs/engineering/NEURIPS_READINESS_PLAN.md`.
- [ ] Resolve the real-benchmark evidence gate or keep GPQA explicitly blocked in the paper.

## Phase 3: Benchmark Author Platform

- Harden benchmark scaffolds, quickstart audits, schema validation, importers, and plugin docs.
- [x] Add metadata-only readiness doctor reports for local artifacts, cache hygiene, and CI gating.
- Expand examples for common local-output formats.
- Add richer author review workflows for item forensics and repair.

## Phase 4: Domain Standardization

- [x] Promote scaffolded domain packs into validated offline diagnostics as fixtures mature.
- [x] Add offline TF-IDF semantic duplicate detection (no paid APIs).
- [x] Add `legendary` audit preset, `audit-summary` CLI, and report-card figures.
- [ ] Add domain-specific reporting templates and repair policies beyond metadata diagnostics.
- Keep heavy dependencies optional.

## Phase 5: Community Standard

- Support external replication bundles.
- Encourage preregistered benchmark-selection protocols.
- Build a registry of validity cards and certificates as evidence profiles.
- Preserve the core rule: validity is not accuracy and never collapses into one scalar score.
