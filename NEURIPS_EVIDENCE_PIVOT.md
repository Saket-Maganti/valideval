# NeurIPS Evidence Pivot

The paper-saving route is:

1. Import published per-instance predictions into a wide response matrix.
2. Ingest independent MMLU-Redux-style issue labels.
3. Export diagnostic flags and validate them against external labels.
4. Run cross-flaw specificity and held-out synthetic validation.
5. Use real/wide-panel IRT only after panel validity passes.
6. Draft the paper from evidence, not hype.

Small local GPQA remains a protocol demonstration. It should not be described as item-validity
evidence.
