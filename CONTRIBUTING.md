# Contributing

ValidEval treats validity as a multidimensional evidence profile. Please keep contributions aligned with that standard.

Before opening a PR:

- Run relevant tests with `python3 -m pytest`.
- Keep toy/demo paths offline and deterministic.
- Add docs and tests for public behavior changes.
- Use cautious language for diagnostic interpretation.
- Avoid required paid APIs and heavyweight optional dependencies in core paths.

Do not add claims that a diagnostic proves global benchmark validity or invalidity.
