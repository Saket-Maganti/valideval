# Discussion

The current evidence supports a cautious real-panel story: subject composition can materially affect
model rankings on the active MMLU panel, while proxy diagnostic weighting does not materially reorder
models relative to accuracy. This is a measurement-sensitivity result, not a claim about the true
model ranking.

The blocked gates matter. MMLU-Redux does not validate error detection under current files, the
decoupled synthetic protocol did not execute, and no second benchmark has a validated panel yet.
