# Later Run Approval Checklist

Before any future run:

- Confirm the exact run family.
- Confirm the command.
- Confirm expected runtime and compute requirements.
- Confirm inputs exist locally.
- Confirm preflight status.
- Record evidence state before execution.
- Record claim state before execution.
- Define the stop rule.
- Get explicit user approval for that one run.

No checklist item authorizes a run by itself.
